# DỰ ÁN QUẢN LÝ QUÁN NET
Dự án làm Winform để tốt nghiệp môn Lập trình Winform, thế thôi!
## Cài đặt và Yêu cầu

Hướng dẫn cài đặt và yêu cầu cần thiết để chạy dự án trên máy tính của bạn.

## Cấu trúc thư mục

Mô tả cấu trúc thư mục của dự án và vai trò của từng thư mục.

## Hướng dẫn sử dụng

Hướng dẫn chi tiết về cách sử dụng dự án. Bao gồm các bước để chạy ứng dụng và sử dụng các tính năng cụ thể.

## Công nghệ sử dụng

- .Net Framework 4.8
- SQL Server (LocalDB)
- Công nghệ lập trình chạy bằng cơm và nước tương
